# MyJPJ RAG Policy Assistant

**Author:** Muhammad Syazwan Bin Mahad
**Course:** CSC649 — Special Topics in Computer Science  
**Specialized Technology:** Natural Language Processing (NLP) & Retrieval-Augmented Generation (RAG)

## Project Overview
This project proposes a conversational policy assistant integrated into the MyJPJ mobile application. Using Retrieval-Augmented Generation (RAG), the assistant answers motorist questions in English and Bahasa Melayu regarding traffic rules, driving license renewal requirements, demerit points, and vehicle ownership changes—grounded strictly in official Jabatan Pengangkutan Jalan (JPJ) FAQs and summons regulations with verifiable source attribution.

## Problem Summary
Malaysian drivers, motorcyclists, and vehicle owners using the MyJPJ mobile application currently navigate plain FAQ pages and separate official portals that explain complex procedural rules manually. This friction leads to abandoned self-service transactions, missed renewal deadlines, and overloaded JPJ physical counters and MyGCC call centers.
