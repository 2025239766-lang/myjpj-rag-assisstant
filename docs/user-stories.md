# B3. User Stories and Acceptance Criteria

| ID | User Story | Acceptance Criteria |
| :--- | :--- | :--- |
| **US1**<br>*(FR1 and FR3)* | As a local Malay driver, I want to ask the MyJPJ assistant ChatBot how to renew an expired driving license in my preferred language, so that I do not have to search through lengthy FAQ pages in a language I barely understand. | 1) Inputting `"How to change the license from P to competent?"` will allow the AI assistant to guide the user by showing the steps that should be taken in less than 3 seconds.<br><br>2) Entering the same question in Bahasa Melayu (`"Bagaimana cara menukar lesen dari P kepada lesen kompeten"`) will display the answer based on the official JPJ FAQ pages. |
| **US2**<br>*(FR2 and FR4)* | As a vehicle owner with an unpaid summons, I want to see which official JPJ guideline bolsters the AI assistant's elaboration about the license status changes, so that I can confirm the rule before visiting a physical JPJ counter. | 1) Every answer includes a solid, labeled citation pointing to the related passages in the JPJ FAQ or showing the guideline section itself.<br><br>2) Inputting an unsupported traffic rule will display a `"No official JPJ guideline found for this query"` message rather than making up an answer. |
| **US3**<br>*(FR5)* | As a lack-of-knowledge MyJPJ user, I want to transfer my chat session to an actual human JPJ support officer when the AI assistant cannot fulfill my account blacklist issue, so that I can receive personalized professional assistance. | 1) Tapping `"Talk to Live Officer"` changes the respondent from the AI assistant to a real-time support officer in less than 2 taps.<br><br>2) The user's previous chat history will automatically be passed to the live support session so they do not have to repeat the question. |
