# Part B: Requirements

## B1. Functional Requirements

| ID | Functional Requirements |
| :--- | :--- |
| **FR1** | The system shall allow users to input questions in English or Bahasa Melayu in the AI chatbot. |
| **FR2** | The system shall reply to the user's input query with the most relevant (if available) passages from the official JPJ FAQs and summons guidelines. |
| **FR3** | The system shall generate a response according to the retrieved JPJ passages and guidelines. |
| **FR4** | The system shall provide the actual official JPJ FAQ passages as a reference. |
| **FR5** | The system shall provide a button to change the current chat respondent into a live JPJ support officer in case the AI chatbot is not helping with the issue. |

## B2. Non-Functional Requirements

| ID | Quality Category | Non-Functional Requirement |
| :--- | :--- | :--- |
| **NFR1** | Performance | The system shall generate a complete response within 3 seconds under standard 4G/5G mobile network conditions. |
| **NFR2** | Security & Privacy | The system shall detect and mask 12-digit MyKad numbers and vehicle plate numbers before storing chat logs, complying with Malaysia's Personal Data Protection Act (PDPA). |
| **NFR3** | Usability | The system shall allow users to initiate or interact with a live assistant ChatBot within 2 taps from the homepage dashboard. |
